## Notes

- `pagila.payment` is the union of the 55 monthly partitions listed on the last row; the
  partitions are kept so partition pruning can be compared against the union.
- Every `pagila.*` and every CSV-sourced `raw.*` column is `VARCHAR` on purpose. Typing them
  is Q2's work; inferring it at load time would hide the defects.
- `raw.taxi_trips` keeps its Parquet types, because Parquet is already typed.
- A column being unique is not the same as it being the key. `pagila.film` has five unique
  columns but only `film_id` is the primary key — the rest are unique by coincidence of this
  data, and would collide on a bigger extract.
